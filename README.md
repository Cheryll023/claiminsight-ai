# ClaimInsight AI（理析）

**AI-powered Insurance Conversation Analytics Platform**

理析是一款面向保险理赔与消费者权益保护（消保）场景的 AI 对话分析平台，旨在帮助业务人员从大量客户通话录音中快速提取有价值的信息。

### Key Features

- **Batch Audio Processing** — 支持批量录音上传、压缩包解析与案件自动归类。
- **Speech-to-Text** — 将客户沟通录音转换为可检索的文字内容。
- **AI Case Analysis** — 自动提取客户诉求、工作人员回应、争议焦点及待跟进事项。
- **Complaint & Sentiment Analysis** — 分析投诉原因、客户情绪表达及潜在风险信号。
- **Knowledge-Grounded AI Assistant** — 结合保险条款、内部制度和案件上下文提供智能问答及处理建议。
- **Business Insights** — 汇总客户高频诉求与业务问题，辅助管理人员了解服务情况。

### Project Goal

Transform unstructured insurance conversations into actionable business insights through AI-powered speech analysis, contextual understanding, and knowledge-grounded assistance.
